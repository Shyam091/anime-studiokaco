## 📖 Overview

Anime StudioKaCo is a modern anime search application built with **React**.

Users can search for any anime and instantly get:

- 🖼️ Anime Poster
- ⭐ Rating
- 📺 Episode Count
- 📝 Short Synopsis

The project demonstrates working with REST APIs using **Fetch API**, **Async/Await**, **React Hooks**, and **Conditional Rendering** while providing a smooth and responsive user interface.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/anime-studiokaco.git
```

### Navigate to the project

```bash
cd anime-studiokaco
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
